Civic Pulse

Bersama, Untuk Lingkungan Kita.

Gunakan menu bawah untuk melihat Beranda, Komunitas, Event, Mutual Help, dan Profil.

Semua kegiatan, lokasi, dan bantuan adalah data contoh tetap. Pencarian, edit profil, rute, tambah event, ikut event, gabung komunitas, serta bantuan belum diaktifkan.

Login latihan: username dan password harus sama, misalnya chia / chia. Logout tersedia di menu Toolbar dan Profil.

Pilih chip di halaman daftar untuk menyaring kategori. Beranda menampilkan empat ikon dalam satu baris; ikon ini belum membuka halaman. Tutorial tiga halaman tersedia dari ikon informasi pada Komunitas.
